# classes/

Aquí hi van a parar les classes publicades des de l'app. Per cada classe hi ha
dos fitxers, escrits automàticament des de **Configuració › Publicar per als
alumnes**:

- `<identificador>.json` — l'agenda que llegeix la vista d'alumne.
- `<identificador>.ics` — el mateix, en format calendari, per subscriure-s'hi.

No cal editar-los a mà: es reescriuen sencers a cada publicació. Esborrar-los
deixa l'enllaç dels alumnes sense contingut.

Els fitxers són públics per a qui tingui l'enllaç, així que **no hi ha d'haver
mai dades personals d'alumnes** a les entrades de l'agenda.
